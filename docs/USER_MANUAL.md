## 1. 环境要求与启动

### 1.1 系统要求

| 要求 | 最小 | 推荐 |
|------|-----|------|
| JDK | 17+ | 17 LTS 或更高 |
| 内存 | 256 MB | 1 GB+ |
| 磁盘 | 100 MB | 500 MB |
| 屏幕分辨率 | 1280×720 | 1920×1080+ |
| 操作系统 | Windows 10 / Linux / macOS 12+ | 麒麟 V10 SP1 |

### 1.2 启动方式

**Linux / macOS:**
```bash
tar -xzf kylin-sql-*.tar.gz
cd kylin-sql-*
./kylin-sql.sh
```

**Windows:**
双击 `kylin-sql.bat` 即可启动。

**麒麟 DEB 包:**
```bash
sudo dpkg -i kylin-sql-*.deb
kylin-sql
```

启动脚本会自动检测系统中版本最高的 JDK 17+（优先使用内置 JDK，再检测 `JAVA_HOME`，最后搜索系统 `PATH`），无需手动设置。

### 1.3 启动画面

启动时显示 Splash 窗口，依次经过以下阶段后主界面出现：
1. 加载配置
2. 构建工具栏/菜单
3. 构建面板
4. 加载已保存连接
5. 恢复工作区（标签页、内容、连接、Schema）
6. 刷新对象树

## 3. 数据库连接

### 3.1 支持的数据库

| 数据库 | 标识 Key | 默认端口 | 协议族 |
|--------|----------|---------|--------|
| Oracle | `oracle` | 1521 | ORACLE |
| OceanBase (Oracle 模式) | `oceanbase-oracle` | 2883 | ORACLE |
| OceanBase (MySQL 模式) | `oceanbase-mysql` | 2883 | MYSQL |
| MySQL | `mysql` | 3306 | MYSQL |
| MariaDB | `mariadb` | 3306 | MYSQL |
| PostgreSQL | `postgresql` | 5432 | OTHER |

### 3.2 新建连接

1. 点击工具栏 **连接管理** 按钮（🔗 图标）或菜单 `文件 → 管理连接`
2. 在连接对话框中点击 **新建**
3. 选择数据库类型，填写连接信息：
   - 连接名称（自定义标识）
   - 主机名 / 端口
   - 数据库名 / 服务名
   - 用户名 / 密码
   - 查询超时（0 = 不限）
4. 点击 **测试连接** 确认连通性
5. 点击 **保存**

> 保存的连接会出现在左侧对象浏览器和编辑器顶部的连接下拉框中。

### 3.3 连接管理

- **编辑**：修改已有连接参数
- **删除**：移除连接（不会影响数据库）
- **颜色标记**：每个连接可设置颜色，在对象树中区分
- **自动重连**：连接断开时自动尝试重连
- **连接池**：基于 HikariCP，无需手动管理

### 3.4 Schema 切换

每个编辑器标签可在顶部工具栏独立选择连接和 Schema。切换 Schema 后自动加载该 Schema 下的对象列表。

## 4. SQL 编辑器

### 4.1 基本操作

| 操作 | 说明 |
|------|------|
| 新建文件 | `Ctrl+N`，创建空白编辑标签 |
| 打开文件 | `Ctrl+O`，从文件系统加载 `.sql` 文件 |
| 保存 | `Ctrl+S`，文件模式写入磁盘；未命名文件弹框选择路径 |
| 另存为 | `Ctrl+Shift+S` |
| 关闭标签 | `Ctrl+W`（未保存时提示） |
| 同时编辑 | 可打开多个标签，每个独立连接和 Schema |
| 工作区恢复 | 重启后自动恢复上次打开的标签内容、连接、Schema |

### 4.2 语法高亮

基于 RSyntaxTextArea 3.6，自定义 `PlSqlTokenMaker`，支持：
- SQL 关键字（SELECT、FROM、WHERE 等）
- PL/SQL 关键字（BEGIN、END、LOOP、DECLARE 等）
- 字符串、数字、注释
- 操作符、分隔符
- 折叠标记（语法折叠 + 代码块折叠）

### 4.3 自动补全

基于 `PlSqlCompletionProvider` + `MetadataCache`，支持：
- **表名 / 视图名**：从元数据缓存中查询
- **列名**：在表名后输入 `.` 触发列补全
- **关键字**：262 个 PL/SQL 关键字
- 延迟 300ms 自动弹出
- 单匹配时自动填充

### 4.4 SQL 执行

**执行方式：**
- `F8` 或 `Ctrl+Shift+F10`：执行当前 SQL 语句（光标所在分号段，选区优先）
- `F9`：追加执行（保留之前的结果）

**执行反馈：**
- 行号区显示绿色 ✓（成功）或红色 ❗（失败）
- 底部消息面板记录执行时间、耗时、影响行数
- 结果集以表格形式展示在结果面板

### 4.5 执行计划

按 `Ctrl+E` 或菜单 `SQL → 执行计划`，查看当前 SQL 的 EXPLAIN PLAN 结果。

### 4.6 文本缩放

| 操作 | 快捷键 |
|------|--------|
| 放大 | `Ctrl++` 或 `Ctrl+鼠标滚轮↑` |
| 缩小 | `Ctrl+-` 或 `Ctrl+鼠标滚轮↓` |
| 重置 | `Ctrl+0` |

### 4.7 搜索替换

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 查找 | `Ctrl+F` | 打开搜索面板，增量搜索 |
| 替换 | `Ctrl+R` | 打开搜索替换面板 |
| 查找下一个 | `F3` | 编辑器焦点时 |
| 查找上一个 | `Shift+F3` | |
| 关闭面板 | `Escape` | |

搜索面板支持输入历史记忆（↑/↓ 导航）。

### 4.8 标签右键菜单

右键单击标签弹出菜单，包含：

| 功能 | 说明 |
|------|------|
| 关闭 / 关闭其他 / 关闭全部 / 关闭未修改 | 标签管理 |
| 关闭左侧标签 / 关闭右侧标签 | 批量关闭 |
| 固定 / 取消固定 | 防止意外关闭 |
| 向右拆分 / 向下拆分 | 分屏编辑 |
| 执行 (Ctrl+Shift+F10) | 运行当前标签 SQL |
| 另存为 | 保存当前内容到文件 |
| 复制文件名 / 复制完整路径 | 复制到剪贴板 |
| 用其他方式打开 | 文件管理器 / 终端 / 外部编辑器 |
| 本地历史 | 显示历史 / 对比上个版本 / 恢复 |
| 重新打开已关闭标签 | 恢复最近关闭的标签（最多 15 个） |

### 4.9 本地历史

每次保存文件时，自动备份到 `~/.kylin-sql/.local-history/`：
- **显示历史**：查看所有历史版本列表
- **对比上个版本**：与最近历史版本行级对比
- **恢复**：选择历史版本覆盖当前内容
- 每个文件保留最近 30 个版本

### 4.10 源码查看器

双击对象浏览器的包/过程/函数节点，以只读方式打开：
- **包 (PACKAGE)**：左侧方法导航列表 + 右侧代码编辑器；Spec/Body 子标签切换
- **存储过程/函数**：仅有代码编辑器视图
- **编辑/保存/编译**：点击 E 按钮进入编辑 → S 保存 → C 编译
- 支持工作区恢复

## 5. 对象浏览器

### 5.1 数据结构

左侧 DATABASE 面板以树形结构展示当前连接下的数据库对象：

```
连接名 (颜色标记)
├── Schema1
│   ├── 表 (Tables)
│   ├── 视图 (Views)
│   ├── 序列 (Sequences)
│   ├── 索引 (Indexes)
│   ├── 同义词 (Synonyms)
│   ├── 函数 (Functions)
│   └── 过程 (Procedures)
│       └── 包名 (可展开查看内部方法)
└── Schema2
    └── ...
```

### 5.2 操作

| 操作 | 效果 |
|------|------|
| 单击节点 | 复制节点文本到剪贴板 |
| 双击表/视图 | 数据预览（前 100 行） |
| 右键 → 生成 SELECT | 生成查询模板 |
| 右键 → 生成 INSERT | 生成插入模板 |
| 右键 → 生成 UPDATE | 生成更新模板 |
| 右键 → 生成 DELETE | 生成删除模板 |
| 右键 → 查看 DDL | 显示对象 DDL |
| 右键 → 刷新 | 重新加载当前节点 |
| 右键 → 展开包 | 展开包内函数/过程列表 |
| 双击包/函数/过程 | 以源码查看器打开 |
| 点击 DATABASE 标签 | 折叠/展开左侧面板 |

### 5.3 元数据配置

通过 `工具 → 设置 → 元数据配置`，可自定义每种数据库类型的对象浏览器查询行为：
- Oracle / OceanBase (Oracle 模式) / OceanBase (MySQL 模式) / MySQL / MariaDB / PostgreSQL 六种类型独立配置
- 每类可独立启用/禁用自定义配置，禁用时使用内置硬编码查询模板
- 类型定义表格：每个类型（表/视图/包等）可配置标签、类型码、查询来源（SQL / FIXED_LIST）、是否可展开
- 自定义列表：添加额外列在树节点上渲染
- 恢复默认：一键重置为内置默认配置

### 5.4 本地文件浏览器

DATABASE 面板下方内嵌本地文件浏览器，支持：
- 添加/移除根目录
- 文件树浏览
- 右键菜单：打开、打开所在位置、复制路径、刷新
- `.sql` 文件双击在编辑器中打开

## 6. 右侧面板

### 6.1 FILES 标签

列出已保存/打开的 SQL 文件，按最近使用排序：
- 文件名（白色）+ 文件路径（灰色，超长截断，悬浮显示完整路径）

- 右键菜单：打开、打开所在位置、删除、永久删除

### 6.2 THUMBNAIL 标签

当前编辑器的迷你缩略图概览：
- 每行渲染为水平条
- 彩色条标记当前光标行
- 点击/拖拽跳转到编辑器对应行

## 7. 数据导出

### 7.1 导出格式

| 格式 | 说明 | 需要表名 | 需要方言 |
|------|------|---------|---------|
| **INSERT** | SQL INSERT 语句 | 是 | 是 |
| **CSV** | 逗号分隔值，UTF-8 BOM | 否 | 否 |
| **JSON** | JSON 数组格式 | 否 | 否 |
| **XML** | XML 文档格式 | 否 | 否 |
| **Markdown** | Markdown 表格 | 否 | 否 |

INSERT 语句支持 4 种方言：Oracle / MySQL / PostgreSQL / ANSI SQL。

### 7.2 导出模式

**简单导出**（`ExportDialog`）：
- 结果集导出为 INSERT / CSV / JSON / XML / Markdown
- 配置选项：日期格式、NULL 值处理、行分隔符

**高级导出**（`AdvancedExportDialog`）：
- **结果集模式**：导出当前查询结果
- **表模式**：选择连接 → Schema → Table，级联加载表列，预览 10 行数据
- **自定义 SQL 模式**：输入 SQL 查询后导出
- 支持后台批量任务管理

## 8. SQL 格式化引擎

### 8.1 支持的方言

| 方言 | 说明 |
|------|------|
| Oracle PL/SQL | 存储过程、函数、包、触发器、游标、异常处理 |
| OceanBase (Oracle 模式) | 同 Oracle 语法 |
| MySQL | MySQL 5.7 / 8.0+ |
| PostgreSQL | PL/pgSQL |

### 8.2 格式化配置（40+ 参数）

| 类别 | 参数举例 |
|------|---------|
| 关键字大小写 | UPPER / lower / Original / Capitalize |
| 缩进 | 缩进大小（2/4/8）、Tab 宽度 |
| 行宽 | 最大行宽、断行策略 |
| 逗号 | 前置/后置/前后空格 |
| WHERE | AND 位置（行首/行尾）、对齐 |
| SELECT | 列换行模式、别名对齐 |
| 注释 | 注释缩进、位置、对齐 |
| 子查询 | Inline / Expand / Auto |
| 括号 | 空格、换行、对齐 |
| CTE | WITH 子句格式 |
| INSERT | 列插入格式 |
| DDL | 存储子句格式、分区格式 |

### 8.3 预设配置

| 预设 | 说明 |
|------|------|
| 默认 (Oracle) | 标准 Oracle PL/SQL 风格 |
| Expanded | 展开风格，每行一列 |
| Compact | 紧凑风格 |

### 8.4 格式化引擎

| 引擎 | 说明 |
|------|------|
| **Kylin 格式化引擎**（默认） | 模板驱动，4 阶段约束求解器：结构解析 → 行宽 → 对齐 → 合并 |
| **JSQLFormatter** | 基于 JSQLParser AST 的第三方引擎 |
| **Simple 格式化** | 简单 Token 流引擎 |
| **自定义格式化** | 用户可自定义规则 |

按 `Ctrl+Shift+F` 使用当前引擎格式化，可在工具栏下拉框切换引擎。

## 9. 内置工具

所有工具可通过 `工具` 菜单访问：

### 9.1 SQL 工具（`Ctrl+Shift+T`）

三个功能区集成在一个对话框：

| 功能 | 说明 |
|------|------|
| **字符串转义** | SQL 单引号转义/反转义（`'` ↔ `''`） |
| **IN 格式转换** | 输入一组值 → 生成 `('a','b')` 格式 IN 子句；支持反向解析 |
| **SQL 格式化** | 快速格式化 SQL 文本，独立窗口不占用编辑器 |

### 9.2 数据生成器

基于表结构智能生成测试数据：
- 选择连接 + Schema + 表 → 自动读取列名和数据类型
- 每列可配置生成规则：随机字符串（定长/变长）、自增整数、枚举值、日期区间随机、从已有数据取样
- 一键生成 INSERT 语句，可直接执行或复制

### 9.3 SQL 历史（`Ctrl+Shift+H`）

浏览当前会话执行过的所有 SQL：
- 列表展示：SQL 文本、执行耗时、影响行数、时间戳、连接/Schema
- 搜索过滤 → 双击回填编辑器或重新执行
- 收藏常用 SQL
- 可清空历史

### 9.4 文本比较

双栏对比两段文本/SQL 差异：
- 左右语法高亮编辑器
- 行级 diff 高亮（增色/删色/改色）
- 可忽略空白差异
- 支持从文件加载

### 9.5 正则测试器

实时测试正则表达式：
- 输入正则 + 测试文本 → 实时高亮所有匹配
- 显示匹配数量、分组捕获内容
- 常用正则收藏管理

### 9.6 对象搜索（`Ctrl+P`）

全局搜索数据库对象：
- 输入关键词，跨所有 Schema 搜索表/视图/索引/序列/函数/过程/包
- 结果列表显示对象名、类型、所属 Schema
- 双击跳转到对象浏览器对应节点

### 9.7 调用层次（`Ctrl+Alt+H`）

分析 PL/SQL 对象的调用依赖关系树。

### 9.8 导入

支持从 SQL 文件或 CSV 文件导入数据到数据库表。

## 10. 主题切换

### 10.1 内置主题

菜单 `视图 → 主题`：

| 主题 | 类型 | 特点 |
|------|------|------|
| **Darcula** | 深色 | 默认主题，类似 IntelliJ Darcula |
| **Light** | 浅色 | DataGrip 风格浅色主题 |
| **豆沙绿** | 绿色 | 护眼主题 |

切换后编辑器、左侧树、底部面板等所有组件自动同步主题色。

### 10.2 个性化颜色

在 `工具 → 设置 → 主题个性化` 中可覆盖任意颜色键：
- 背景组：主背景、编辑器背景、面板背景、工具栏背景、输出背景
- 前景组：主文本、次要文本、标题、标签页颜色
- 选择组：选中背景/文字颜色
- 边框组：默认/浅边框
- 自定义颜色后点击 **应用** 生效
- 点击 **重置** 恢复主题默认值

## 11. 设置

菜单 `文件 → 设置`（`Ctrl+Alt+S`）打开设置对话框，左侧导航树：

| 节点 | 功能 |
|------|------|
| **主题个性化** | 颜色覆盖（见 10.2） |

## 14. 故障排除

### 14.1 启动失败

**错误：未找到 JDK 17。**
- 安装 JDK 17: `sudo apt install openjdk-17-jdk`
- 或设置 `JAVA_HOME` 环境变量指向 JDK 17 安装目录

**Splash 窗口卡住后退出：**
- 检查日志文件 `~/.kylin-sql/logs/kylin-sql.log`
- 菜单 `帮助 → 应用日志` 查看运行时日志

### 14.2 连接失败

- 检查主机名/端口是否正确
- 检查用户名/密码
- 检查网络是否可达
- 检查数据库服务是否运行
- OceanBase 默认端口: 2883（OBProxy 模式）
- MySQL 默认端口: 3306
- Oracle 默认端口: 1521
- PostgreSQL 默认端口: 5432

### 14.3 对象浏览器不显示对象

- 确认连接已保存且状态为"已连接"
- 右键连接节点选择"刷新"
- 检查元数据配置是否被意外修改
- 工具 → 设置 → 元数据配置 → 恢复默认

### 14.4 格式化结果不符合预期

- 工具栏下拉框切换格式化引擎
- 工具 → 设置 → SQL 格式化 调整参数
- 从预设下拉框选择预设（默认/展开/紧凑）

### 14.5 查看日志

菜单 `帮助 → 应用日志` 或 `~/.kylin-sql/logs/kylin-sql.log`。
