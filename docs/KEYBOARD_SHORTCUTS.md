# Kylin SQL Developer 快捷键速查表

## 全局快捷键（菜单栏 + 全局绑定）

### 文件操作

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Ctrl+N` | 新建 SQL 文件 | 创建新的空白编辑器标签 |
| `Ctrl+O` | 打开 SQL 文件 | 从文件系统加载 .sql 文件 |
| `Ctrl+S` | 保存 | 保存当前文件（文件模式下写入磁盘） |
| `Ctrl+Shift+S` | 另存为 | 保存到新路径 |
| `Ctrl+W` | 关闭当前标签 | 关闭当前编辑器标签页 |
| `Ctrl+Alt+S` | 设置 | 打开设置对话框 |

### 编辑操作

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Ctrl+Z` | 撤销 | 撤销上一步操作 |
| `Ctrl+Y` | 重做 | 重做已撤销的操作 |
| `Ctrl+F` | 查找 | 打开搜索面板（编辑器内） |
| `Ctrl+R` | 替换 | 打开搜索替换面板（编辑器内） |
| `Ctrl+P` | 全局搜索 | 跨数据库搜索对象名称 |

### SQL 执行

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `F8` / `Ctrl+Shift+F10` | 执行当前 SQL | 执行光标所在分号段（选区优先） |
| `F9` | 追加执行 | 执行新 SQL 并保留之前的结果 |
| `Ctrl+Shift+F` | 格式化 SQL | 使用当前格式化引擎重新排版 SQL |
| `Ctrl+E` | 执行计划 | 查看 SQL 执行计划 (Explain Plan) |
| `Ctrl+Shift+H` | SQL 历史 | 打开 SQL 历史记录面板 |

### 导航

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Ctrl+P` | 全局对象搜索 | 前面板 + 快捷键，跨连接搜索对象 |
| `Ctrl+Shift+H` | SQL 历史 | 打开历史记录对话框 |
| `Ctrl+Alt+H` | 调用层级 | 菜单项标签中有此提示，建议手动从 SQL 菜单触发 |

### 全局补充绑定

| 快捷键 | 操作 | 注册方式 |
|--------|------|---------|
| `Ctrl+Shift+F10` | 执行当前编辑器 | `WHEN_IN_FOCUSED_WINDOW` InputMap |

## 编辑器快捷键 (SqlEditorPanel)

### 文本缩放

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `Ctrl++` (Ctrl+=) | 放大字体 | 步进 +1 |
| `Ctrl+-` | 缩小字体 | 步进 -1 |
| `Ctrl+0` | 重置缩放 | 恢复默认字号 |
| `Ctrl+鼠标滚轮` | 无级缩放 | 范围 6–120 |

### 搜索面板

搜索面板开启状态下（`Ctrl+F` 或 `Ctrl+R`）：

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| `F3` | 查找下一个 | 跳转到下一个匹配项 |
| `Shift+F3` | 查找上一个 | 跳转到上一个匹配项 |
| `↑` (搜索框焦点) | 搜索历史上一条 | 调出历史搜索词 |
| `↓` (搜索框焦点) | 搜索历史下一条 | 调出历史搜索词 |
| `Shift+Enter` (搜索框焦点) | 查找上一个 | 反向搜索 |
| `Escape` (搜索框/替换框焦点) | 关闭搜索面板 | 隐藏搜索替换面板 |

### 编辑器补充说明

| 特性 | 说明 |
|------|------|
| 语句自动检测 | 光标定位到 SQL 语句上自动高亮当前块（分号分隔），按 F8 执行 |
| 执行结果标记 | 执行后在左侧行号区显示绿色 ✓ 或红色 ❗ 图标 |
| 执行日志 | 底部"消息"面板记录每次执行的时间/耗时/行数 |
| 自动补全 | 输入时自动弹出建议列表（表名/列名/关键字） |

## 差异说明

以下快捷键出现在菜单标签或欢迎页中，但**未注册为实际加速键**，建议手动通过菜单触发：

| 显示的文字 | 实际状态 |
|-----------|---------|
| `Ctrl+Alt+H` 调用层级 | 菜单标签显示，但 `setAccelerator` 未设置 |
| `Ctrl+H` 替换 | 欢迎页写的是 Ctrl+H，实际注册的是 `Ctrl+R` |
