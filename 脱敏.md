## 1. 总体架构

```
┌──────────────────────────────────────────────────────────────────┐
│                      AngularJS 1.5 管理页面                       │
│  (脱敏配置 CRUD / 开关实时切换 / 字段级覆盖)                      │

│  1. 读取请求头 X-Masking? 如果有则直接覆盖                       │
│  2. 没有则查 Redis/DB 该 api_pattern 的 enabled 值               │
│  3. 解析 field_config JSON → 存入 MaskingContext                  │
│  4. 设置 MaskingContext (ThreadLocal)                            │
└──────────────────┬───────────────────────────────────────────────┘
                   │
┌──────────────────▼───────────────────────────────────────────────┐
│  Controller / Service / JPA / JDBC (业务不变)                     │
└──────────────────┬───────────────────────────────────────────────┘
                   │ 返回 Entity/DTO
                   ▼
┌──────────────────────────────────────────────────────────────────┐
│  MappingJackson2HttpMessageConverter (httpObjectMapper)          │
│  ├─ MaskingAnnotationIntrospector                                │
│  │   └─ 检测 @SensitiveField 注解 → 绑定 MaskingJsonSerializer   │
│  ├─ MaskingJsonSerializer.serialize()                            │
│  │   1. MaskingContext.isEnabled() == false → 原值               │
│  │   2. 字段覆盖 enabled=false → 原值                            │
│  │   3. 字段覆盖 strategy != null → 用覆盖策略                    │
│  │   4. 否则 → 注解默认策略                                       │
│  └─ 输出已脱敏 JSON                                              │
└──────────────────────────────────────────────────────────────────┘
```

### Redis 集群缓存

```
           ┌──────────┐   ┌──────────┐   ┌──────────┐
           │  实例 A   │   │  实例 B   │   │  实例 C   │
           │ (改配置)  │   │ (读配置)  │   │ (读配置)  │
           └─────┬────┘   └─────┬────┘   └─────┬────┘
                 │              │              │
                 │  每次请求    │              │
                 │  先读 Redis  │              │
                 ▼              ▼              ▼
          ┌────────────── Redis Cluster ───────────────┐
          │  Key: mask:config:list                     │
          │  Value: JSON([{api,enabled,fieldConfig}...])│
          │  TTL: 600s                                  │
          │  命中 → 直接匹配，不查 DB                   │
          │  MISS → 回源 DB → 写回 Redis               │
          └────────────────────────────────────────────┘
                          ▲
                          │ (MISS 时回源)
                          ▼
                 ┌─────────────── DB ───────────────┐
                 │  sys_masking_config (共享表)      │
                 └──────────────────────────────────┘

    配置更新流程（所有实例实时生效）:
    1. 任一实例更新 DB
    2. 该实例 DELETE mask:config:list
    3. 其他实例下一次请求 Redis MISS → 回源 DB → 拿到新配置
    4. 延迟 = 一次 Redis GET + 一次 DB 查询 ≈ <10ms
```

## 3. 数据库表设计

```sql
CREATE TABLE sys_masking_config (
  id           BIGINT       AUTO_INCREMENT PRIMARY KEY,
  module       VARCHAR(50)  NOT NULL DEFAULT '' COMMENT '模块名称: user/order/payment',
  api_pattern  VARCHAR(300) NOT NULL COMMENT 'Ant风格接口路径 /api/user/**',
  enabled      TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '脱敏开关 1=开 0=关',
  field_config TEXT                  DEFAULT NULL COMMENT '字段级覆盖 JSON，NULL=用注解默认值',
  status       TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '状态 1=正常 0=删除',
  remark       VARCHAR(500)          DEFAULT '' COMMENT '备注说明',
  created_at   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at   DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_api_pattern (api_pattern),
  KEY idx_module (module),
  KEY idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='数据脱敏接口配置';
```

> **设计思路**: 接口级开关 `enabled` 控制整体，字段级覆盖通过 `field_config` JSON 实现。
> - `field_config = NULL` → 所有字段用注解默认值
> - `field_config = {"phone":{"enabled":false}}` → phone 字段不脱敏（覆盖注解）
> - `field_config = {"phone":{"strategy":"PHONE_LAST4"}}` → phone 用指定策略

**field_config JSON 结构**:

```json
{
  "字段名": {
    "enabled": true/false,   // 可选，null=不覆盖注解
    "strategy": "PHONE"      // 可选，null=不覆盖注解
  }
}
```

**单字段示例** — 只关闭 phone 脱敏:

```json
{"phone": {"enabled": false}}
```

**多字段示例** — phone 关闭脱敏，email 替换策略，idCard 强制开启:

```json
{
  "phone":  {"enabled": false},
  "email":  {"strategy": "EMAIL"},
  "idCard": {"enabled": true, "strategy": "ID_CARD"}
}
```

**混合示例** — 3 个字段各有不同覆盖:

```json
{
  "phone":  {"enabled": false},
  "bankCard": {"strategy": "BANK_CARD", "enabled": true},
  "address": {"strategy": "ADDRESS"}
}
```

> **字段不在 JSON 中** → 用注解 `@SensitiveField` 的默认值

**初始数据示例**:

```sql
INSERT INTO sys_masking_config (module, api_pattern, enabled, field_config) VALUES
('user',    '/api/user/**',    1, '{"phone":{"enabled":false},"email":{"strategy":"EMAIL"}}'),
('user',    '/api/user/admin', 1, '{"phone":{"enabled":true,"strategy":"PHONE_LAST4"}}'),
('order',   '/api/order/**',   1, '{"receiverName":{"strategy":"CHINESE_NAME"},"receiverPhone":{"strategy":"PHONE"}}'),
('payment', '/api/payment/**', 1, NULL),
('common',  '/api/common/**',  0, NULL);
```

### 实体类 `MaskingConfig`

```java
package com.yourcompany.web.entity;

import javax.persistence.*;
import java.time.LocalDateTime;

@Entity
@Table(name = "sys_masking_config")
public class MaskingConfig {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    /** 模块名称: user/order/payment */
    @Column(name = "module", length = 50, nullable = false)
    private String module;

    /** Ant风格接口路径，如 /api/user/** */
    @Column(name = "api_pattern", length = 300, nullable = false, unique = true)
    private String apiPattern;

    /** 脱敏开关: 1=开 0=关 */
    @Column(name = "enabled", nullable = false)
    private Boolean enabled = true;

    /** 字段级覆盖配置 JSON，NULL=用注解默认值 */
    @Column(name = "field_config", columnDefinition = "TEXT")
    private String fieldConfig;

    /** 状态: 1=正常 0=删除 */
    @Column(name = "status", nullable = false)
    private Integer status = 1;

    /** 备注 */
    @Column(name = "remark", length = 500)
    private String remark;

    @Column(name = "created_at", updatable = false)
    private LocalDateTime createdAt;

    @Column(name = "updated_at")
    private LocalDateTime updatedAt;

    @PrePersist
    protected void onCreate() {
        createdAt = LocalDateTime.now();
        updatedAt = LocalDateTime.now();
        if (status == null) status = 1;
        if (enabled == null) enabled = true;
    }

    @PreUpdate
    protected void onUpdate() {
        updatedAt = LocalDateTime.now();
    }

    // getter / setter
    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }

    public String getModule() { return module; }
    public void setModule(String module) { this.module = module; }

    public String getApiPattern() { return apiPattern; }
    public void setApiPattern(String apiPattern) { this.apiPattern = apiPattern; }

    public Boolean getEnabled() { return enabled; }
    public void setEnabled(Boolean enabled) { this.enabled = enabled; }

    public String getFieldConfig() { return fieldConfig; }
    public void setFieldConfig(String fieldConfig) { this.fieldConfig = fieldConfig; }

    public Integer getStatus() { return status; }
    public void setStatus(Integer status) { this.status = status; }

    public String getRemark() { return remark; }
    public void setRemark(String remark) { this.remark = remark; }

    public LocalDateTime getCreatedAt() { return createdAt; }
    public LocalDateTime getUpdatedAt() { return updatedAt; }
}
```

### 4.1 注解 `@SensitiveField`

```java
package com.yourcompany.common.annotation;

import com.yourcompany.common.enums.MaskingStrategy;

import java.lang.annotation.*;

/**
 * 标记敏感字段，在 Jackson HTTP 序列化时自动脱敏。
 * 不影响 Redis 序列化（Redis 使用独立 ObjectMapper）。
 */
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface SensitiveField {

    /** 脱敏策略 */
    MaskingStrategy strategy();

    /** 掩码字符 */
    char maskChar() default '*';
}
```

### 4.2 脱敏策略枚举 `MaskingStrategy`

```java
package com.yourcompany.common.enums;

import java.util.function.UnaryOperator;

/**
 * 脱敏策略。
 *
 * 每种策略内置边界兼容：
 * - null / 空字符串 → 原样返回
 * - 长度不足标准格式 → 部分保留 + 局部掩码（宁可显少不显多）
 * - 长度符合标准格式 → 标准掩码
 */
public enum MaskingStrategy {

    /** 手机号: 138****1234 */
    PHONE(v -> {
        int len = v.length();
        if (len < 2) return MaskingStrategy.asterisks(len);
        if (len < 7) return v.charAt(0) + MaskingStrategy.asterisks(len - 1);
        if (len < 11) return v.substring(0, 3) + MaskingStrategy.asterisks(len - 3);
        return v.replaceAll("(\\d{3})\\d+(\\d{4})", "$1****$2");
    }),

    /** 手机号: *******1234 (只显示后4位) */
    PHONE_LAST4(v -> {
        int len = v.length();
        if (len <= 4) return v;
        return MaskingStrategy.asterisks(len - 4) + v.substring(len - 4);
    }),

    /** 身份证: 110101********1234 */
    ID_CARD(v -> {
        int len = v.length();
        if (len < 2) return MaskingStrategy.asterisks(len);
        if (len < 6) return v.charAt(0) + MaskingStrategy.asterisks(len - 1);
        if (len < 10) return v.substring(0, 4) + MaskingStrategy.asterisks(len - 4);
        if (len < 15) return v.substring(0, 6) + MaskingStrategy.asterisks(len - 6);
        return v.replaceAll("(\\d{6})\\d+(\\w{4})", "$1********$2");
    }),

    /** 邮箱: a***@domain */
    EMAIL(v -> {
        int at = v.indexOf('@');
        if (at <= 0) {
            int mlen = v.length();
            if (mlen <= 1) return "***";
            return v.charAt(0) + MaskingStrategy.asterisks(mlen - 2) + v.charAt(mlen - 1);
        }
        String name = v.substring(0, at);
        if (name.isEmpty()) return "***" + v.substring(at);
        return name.charAt(0) + "***" + v.substring(at);
    }),

    /** 中文姓名: 张** */
    CHINESE_NAME(v -> {
        if (v.length() <= 1) return "*";
        return v.charAt(0) + MaskingStrategy.asterisks(Math.min(v.length() - 1, 2));
    }),

    /** 固定电话: 010****1234 */
    FIXED_PHONE(v -> {
        int len = v.length();
        if (len < 3) return MaskingStrategy.asterisks(len);
        if (len < 7) return v.substring(0, 2) + MaskingStrategy.asterisks(len - 2);
        if (len < 10) return v.substring(0, 3) + MaskingStrategy.asterisks(len - 3);
        return v.replaceAll("(\\d{3,4})\\d+(\\d{4})", "$1****$2");
    }),

    /** 银行卡: 6222********1234 */
    BANK_CARD(v -> {
        int len = v.length();
        if (len < 3) return MaskingStrategy.asterisks(len);
        if (len <= 4) return v.charAt(0) + MaskingStrategy.asterisks(len - 1);
        if (len <= 8) return v.substring(0, 4) + MaskingStrategy.asterisks(len - 4);
        return v.replaceAll("(\\d{4})\\d+(\\d{4})", "$1********$2");
    }),

    /** 地址: 保留前半段，后半段掩码 */
    ADDRESS(v -> {
        int len = v.length();
        if (len <= 2) return MaskingStrategy.asterisks(len);
        if (len <= 6) return v.substring(0, Math.max(1, len - 2)) + MaskingStrategy.asterisks(Math.min(3, len));
        int keep = Math.min(Math.max(len / 2, 2), 6);
        return v.substring(0, keep) + "***";
    }),

    /** 车牌号: 京A****56 或 京A*****56D */
    LICENSE_PLATE(v -> {
        int len = v.length();
        if (len < 3) return MaskingStrategy.asterisks(len);
        if (len <= 5) return v.substring(0, 2) + MaskingStrategy.asterisks(len - 2);
        if (len <= 7) return v.substring(0, 2) + MaskingStrategy.asterisks(len - 3) + v.substring(len - 1);
        // 新能源7位+1字母尾: 京A12345D → 京A****5D
        return v.substring(0, 2) + MaskingStrategy.asterisks(len - 4) + v.substring(len - 2);
    }),

    /** 密码: 固定全掩 */
    PASSWORD(v -> "******"),

    /** 不脱敏（透传） */
    NONE(UnaryOperator.identity()),

    /** 自定义（需配合正则使用） */
    CUSTOM(UnaryOperator.identity());

    private final UnaryOperator<String> maskFn;

    MaskingStrategy(UnaryOperator<String> maskFn) {
        this.maskFn = maskFn;
    }

    /**
     * 对输入值执行脱敏。
     *
     * @param value 原始值（可为 null 或空）
     * @return 脱敏后的值
     */
    public String mask(String value) {
        if (value == null || value.isEmpty()) return value;
        return maskFn.apply(value);
    }

    /** 生成长度为 count 的掩码字符串（兼容 Java 8+） */
    private static String asterisks(int count) {
        if (count <= 0) return "";
        char[] chars = new char[count];
        java.util.Arrays.fill(chars, '*');
        return new String(chars);
    }
}
```

### 4.3 请求级上下文 `MaskingContext`

```java
package com.yourcompany.common.context;

import java.util.HashMap;
import java.util.Map;

/**
 * 存储当前请求的脱敏状态。
 * 每个请求开始由 MaskingFilter 设置，请求结束自动清除。
 */
public class MaskingContext {

    private static final ThreadLocal<Boolean> ENABLED = ThreadLocal.withInitial(() -> false);
    private static final ThreadLocal<Map<String, FieldOverride>> OVERRIDES =
            ThreadLocal.withInitial(HashMap::new);

    /** 当前请求是否启用了脱敏 */
    public static boolean isEnabled() {
        return ENABLED.get();
    }

    /** 设置脱敏开关 */
    public static void setEnabled(boolean enabled) {
        ENABLED.set(enabled);
    }

    /** 获取字段级覆盖配置（null=用注解默认值） */
    public static FieldOverride getFieldOverride(String fieldName) {
        return OVERRIDES.get().get(fieldName);
    }

    /** 设置字段级覆盖配置 */
    public static void setFieldOverrides(Map<String, FieldOverride> overrides) {
        OVERRIDES.set(overrides != null ? overrides : new HashMap<>());
    }

    /** 请求结束清除（防内存泄漏） */
    public static void clear() {
        ENABLED.remove();
        OVERRIDES.remove();
    }

    /**
     * 字段级覆盖配置。
     * 用于覆盖 @SensitiveField 注解的默认行为。
     */
    public static class FieldOverride {
        /** true=强制开启脱敏, false=关闭脱敏, null=不覆盖注解 */
        private Boolean enabled;
        /** 替换策略名（如 "PHONE_LAST4"），null=不覆盖注解 */
        private String strategy;

        public FieldOverride() {}

        public FieldOverride(Boolean enabled, String strategy) {
            this.enabled = enabled;
            this.strategy = strategy;
        }

        public Boolean getEnabled() { return enabled; }
        public void setEnabled(Boolean enabled) { this.enabled = enabled; }

        public String getStrategy() { return strategy; }
        public void setStrategy(String strategy) { this.strategy = strategy; }
    }
}
```

### 4.4 请求过滤器 `MaskingFilter`

```java
package com.yourcompany.web.filter;

import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.yourcompany.common.context.MaskingContext;
import com.yourcompany.common.context.MaskingContext.FieldOverride;
import com.yourcompany.web.entity.MaskingConfig;
import com.yourcompany.web.service.MaskingConfigService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.stereotype.Component;
import org.springframework.util.AntPathMatcher;
import org.springframework.web.filter.OncePerRequestFilter;

import javax.servlet.FilterChain;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.util.Map;

/**
 * 脱敏过滤器。
 *
 * 决策顺序:
 * 1. 请求头 X-Masking 存在 → 以此为准
 * 2. 无请求头 → 查配置表 api_pattern 匹配结果
 * 3. 无匹配 → 默认 false（不脱敏）
 *
 * 同时加载字段级覆盖配置，存入 MaskingContext 供序列化器使用。
 */
@Component
@Order(Ordered.HIGHEST_PRECEDENCE + 10)
public class MaskingFilter extends OncePerRequestFilter {

    private static final String HEADER_NAME = "X-Masking";
    private static final AntPathMatcher PATH_MATCHER = new AntPathMatcher();

    /** 不需要脱敏的路径（swagger、健康检查等） */
    private static final String[] EXCLUDE_PATTERNS = {
            "/swagger-ui/**", "/v3/api-docs/**",
            "/actuator/**",
            "/api/admin/masking-config/**"
    };

    @Autowired
    private MaskingConfigService configService;

    @Autowired
    private ObjectMapper jsonMapper;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain chain)
            throws javax.servlet.ServletException, java.io.IOException {
        try {
            String path = request.getRequestURI();
            boolean enabled = resolveMaskingEnabled(request);
            MaskingContext.setEnabled(enabled);

            // 加载字段级覆盖配置
            if (enabled) {
                MaskingConfig config = configService.getConfig(path);
                if (config != null && config.getFieldConfig() != null) {
                    try {
                        Map<String, FieldOverride> overrides = jsonMapper.readValue(
                                config.getFieldConfig(),
                                new TypeReference<Map<String, FieldOverride>>() {});
                        MaskingContext.setFieldOverrides(overrides);
                    } catch (Exception e) {
                        // JSON 解析失败，不设置覆盖，用注解默认值
                    }
                }
            }

            chain.doFilter(request, response);
        } finally {
            MaskingContext.clear();
        }
    }

    /** 解析本次请求是否应该脱敏 */
    private boolean resolveMaskingEnabled(HttpServletRequest request) {
        // 排除路径直接返回 false
        String path = request.getRequestURI();
        for (String pattern : EXCLUDE_PATTERNS) {
            if (PATH_MATCHER.match(pattern, path)) return false;
        }

        // 1. 请求头覆盖（最高优先级）
        String header = request.getHeader(HEADER_NAME);
        if (header != null) {
            return "true".equalsIgnoreCase(header) || "1".equals(header);
        }

        // 2. 查询参数覆盖（次优先级，用于 GET 请求调试）
        String param = request.getParameter(HEADER_NAME);
        if (param != null) {
            return "true".equalsIgnoreCase(param) || "1".equals(param);
        }

        // 3. 查配置（Redis/DB）
        return configService.isMaskingEnabled(path);
    }
}
```

### 4.5 Redis 缓存配置 `MaskingConfigService`

```java
package com.yourcompany.web.service;

import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.yourcompany.web.entity.MaskingConfig;
import com.yourcompany.web.repository.MaskingConfigRepository;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.util.AntPathMatcher;

import java.util.List;
import java.util.concurrent.TimeUnit;

/**
 * 脱敏配置服务。
 *
 * 缓存策略（跨集群实时生效）:
 *   Redis → DB（两级缓存，无本地时间缓存）
 *
 * 实时性保证:
 *   toggle/update 时更新 DB → 删除 Redis Key
 *   所有实例下一次请求 Redis MISS → 回源 DB → 拿到新配置
 *   延迟 ≈ 1 次 Redis GET + 1 次 DB 查询 ≈ <10ms
 */
@Service
public class MaskingConfigService {

    private static final String REDIS_KEY = "mask:config:list";
    private static final long REDIS_TTL_SEC = 600;

    @Autowired
    private MaskingConfigRepository repository;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private ObjectMapper jsonMapper;

    private final AntPathMatcher pathMatcher = new AntPathMatcher();

    /**
     * 判断指定请求路径是否启用了脱敏。
     * 每次请求都调用，通过 Redis 保证集群实时一致。
     */
    public boolean isMaskingEnabled(String requestPath) {
        for (MaskingConfig config : getActiveConfigs()) {
            if (pathMatcher.match(config.getApiPattern(), requestPath)) {
                return config.getEnabled();
            }
        }
        return false;
    }

    /** 获取匹配指定路径的配置（含 field_config） */
    public MaskingConfig getConfig(String requestPath) {
        for (MaskingConfig config : getActiveConfigs()) {
            if (pathMatcher.match(config.getApiPattern(), requestPath)) {
                return config;
            }
        }
        return null;
    }

    /**
     * 获取全量配置列表。
     * 1. 读 Redis（JSON 反序列化）
     * 2. MISS → 读 DB → 写入 Redis（600s TTL）
     * 3. 无本地缓存，保证所有实例实时一致
     */
    private List<MaskingConfig> getActiveConfigs() {
        // 1. 尝试从 Redis 读取
        String json = redisTemplate.opsForValue().get(REDIS_KEY);
        if (json != null) {
            try {
                return jsonMapper.readValue(json, new TypeReference<List<MaskingConfig>>() {});
            } catch (Exception e) {
                // JSON 解析失败，忽略，回源 DB
            }
        }

        // 2. Redis MISS → 回源 DB
        List<MaskingConfig> configs = repository.findAllByStatus(1);

        // 3. 写入 Redis（异步非阻塞，即使失败也不影响本次请求）
        try {
            String jsonToCache = jsonMapper.writeValueAsString(configs);
            redisTemplate.opsForValue().set(REDIS_KEY, jsonToCache, REDIS_TTL_SEC, TimeUnit.SECONDS);
        } catch (Exception e) {
            // Redis 写入失败不影响业务
        }

        return configs;
    }

    // ---- CRUD ----

    public List<MaskingConfig> listAll() {
        return repository.findAllByStatus(1);
    }

    public MaskingConfig getById(Long id) {
        return repository.findById(id).orElse(null);
    }

    @Transactional
    public MaskingConfig create(MaskingConfig config) {
        config.setId(null);
        MaskingConfig saved = repository.save(config);
        evictCache();
        return saved;
    }

    @Transactional
    public MaskingConfig update(MaskingConfig config) {
        MaskingConfig existing = repository.findById(config.getId()).orElseThrow();
        existing.setModule(config.getModule());
        existing.setApiPattern(config.getApiPattern());
        existing.setEnabled(config.getEnabled());
        existing.setRemark(config.getRemark());
        // fieldConfig: 前端传了就更新，没传保留原值
        if (config.getFieldConfig() != null) {
            existing.setFieldConfig(config.getFieldConfig());
        }
        MaskingConfig saved = repository.save(existing);
        evictCache();
        return saved;
    }

    /** 核心方法：切换脱敏开关，实时生效 */
    @Transactional
    public void toggle(Long id) {
        MaskingConfig config = repository.findById(id).orElseThrow();
        config.setEnabled(!config.getEnabled());
        repository.save(config);
        evictCache();
    }

    @Transactional
    public void delete(Long id) {
        MaskingConfig config = repository.findById(id).orElseThrow();
        config.setStatus(0);
        repository.save(config);
        evictCache();
    }

    /** 删除 Redis Key，下次任何实例的请求都会 MISS → 重新从 DB 加载 */
    private void evictCache() {
        try {
            redisTemplate.delete(REDIS_KEY);
        } catch (Exception e) {
            // Redis 不可用时，配置变更延迟到 Redis 恢复后生效（TTL 过期）
        }
    }
}
```

### 4.7 脱敏序列化器 `MaskingJsonSerializer`

```java
package com.yourcompany.web.serialize;

import com.fasterxml.jackson.core.JsonGenerator;
import com.fasterxml.jackson.databind.BeanProperty;
import com.fasterxml.jackson.databind.JsonSerializer;
import com.fasterxml.jackson.databind.SerializerProvider;
import com.fasterxml.jackson.databind.ser.ContextualSerializer;
import com.yourcompany.common.annotation.SensitiveField;
import com.yourcompany.common.context.MaskingContext;
import com.yourcompany.common.context.MaskingContext.FieldOverride;
import com.yourcompany.common.enums.MaskingStrategy;

import java.io.IOException;

/**
 * 脱敏 JSON 序列化器。
 *
 * 判断优先级:
 * 1. MaskingContext.isEnabled() == false → 原值
 * 2. 字段级覆盖 enabled=false → 原值
 * 3. 字段级覆盖 strategy != null → 用覆盖策略
 * 4. 注解默认值 → 用注解策略
 */
public class MaskingJsonSerializer extends JsonSerializer<String>
        implements ContextualSerializer {

    private final MaskingStrategy strategy;
    private final String fieldName;

    /** 无参构造函数（Jackson 反序列化需要） */
    public MaskingJsonSerializer() {
        this.strategy = MaskingStrategy.NONE;
        this.fieldName = null;
    }

    public MaskingJsonSerializer(MaskingStrategy strategy, String fieldName) {
        this.strategy = strategy;
        this.fieldName = fieldName;
    }

    @Override
    public void serialize(String value, JsonGenerator gen, SerializerProvider prov)
            throws IOException {

        if (value == null) {
            gen.writeNull();
            return;
        }

        // 1. 接口级开关关闭 → 原值
        if (!MaskingContext.isEnabled()) {
            gen.writeString(value);
            return;
        }

        // 2. 查字段级覆盖
        FieldOverride override = (fieldName != null)
                ? MaskingContext.getFieldOverride(fieldName) : null;

        // 2a. 字段级关闭脱敏 → 原值
        if (override != null && Boolean.FALSE.equals(override.getEnabled())) {
            gen.writeString(value);
            return;
        }

        // 2b. 字段级策略覆盖 → 用覆盖策略
        MaskingStrategy finalStrategy = this.strategy;
        if (override != null && override.getStrategy() != null) {
            try {
                finalStrategy = MaskingStrategy.valueOf(override.getStrategy());
            } catch (IllegalArgumentException e) {
                // 策略名无效，用注解默认值
            }
        }

        // 3. 执行脱敏
        gen.writeString(finalStrategy.mask(value));
    }

    /**
     * 上下文绑定：从字段注解中读取 strategy 和 fieldName，
     * 创建对应的序列化器实例。
     */
    @Override
    public JsonSerializer<?> createContextual(SerializerProvider prov,
                                              BeanProperty property) {
        if (property != null) {
            SensitiveField ann = property.getAnnotation(SensitiveField.class);
            if (ann != null) {
                return new MaskingJsonSerializer(ann.strategy(), property.getName());
            }
        }
        return this;
    }
}
```

```java
package com.yourcompany.web.serialize;

import com.fasterxml.jackson.databind.introspect.Annotated;
import com.fasterxml.jackson.databind.introspect.JacksonAnnotationIntrospector;

    public Object findSerializer(Annotated a) {
        SensitiveField ann = _findAnnotation(a, SensitiveField.class);
        if (ann != null) {
            return MaskingJsonSerializer.class;
        }
        return super.findSerializer(a);
    }
}
```

```java
package com.yourcompany.web.config;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.boot.autoconfigure.condition.ConditionalOnClass;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.serializer.Jackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

@Configuration
@ConditionalOnClass(RedisTemplate.class)
public class RedisConfig {

    private final ObjectMapper redisObjectMapper;

    public RedisConfig(@Qualifier("redisObjectMapper") ObjectMapper redisObjectMapper) {
        this.redisObjectMapper = redisObjectMapper;
    }

    /**
     * RedisTemplate 使用独立的 redisObjectMapper。
     * @SensitiveField 注解在此 ObjectMapper 中不被识别，
     * 因此 Redis 中存储的是字段原值，不受脱敏影响。
     */
    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);

        // Key 使用 String 序列化
        template.setKeySerializer(StringRedisSerializer.UTF_8);
        template.setHashKeySerializer(StringRedisSerializer.UTF_8);

        // Value 使用自定义 redisObjectMapper
        Jackson2JsonRedisSerializer<Object> serializer =
                new Jackson2JsonRedisSerializer<>(redisObjectMapper, Object.class);
        template.setValueSerializer(serializer);
        template.setHashValueSerializer(serializer);

        template.afterPropertiesSet();
        return template;
    }
}
```

### 6.3 控制器

```javascript
// controllers/admin/MaskingConfigController.js
angular.module('app').controller('MaskingConfigController',
    ['$scope', '$http', 'AlertService', MaskingConfigController]);

function MaskingConfigController($scope, $http, AlertService) {
    var vm = this;
    vm.list = [];

    // 加载列表
    function loadList() {
        $http.get('/api/admin/masking-config').then(function(resp) {
            var data = resp.data.data || [];
            // 解析每条配置的 fieldConfig JSON
            data.forEach(function(item) {
                item.fieldList = parseFieldConfig(item.fieldConfig);
            });
            vm.list = data;
        });
    }

    /**
     * 解析 fieldConfig JSON 字符串为数组。
     * 输入: '{"phone":{"enabled":false},"email":{"strategy":"EMAIL"}}'
     * 输出: [{name:'phone', enabled:false, strategy:null},
     *        {name:'email', enabled:null,  strategy:'EMAIL'}]
     */
    function parseFieldConfig(json) {
        if (!json) return [];
        try {
            var obj = typeof json === 'string' ? JSON.parse(json) : json;
            var list = [];
            for (var key in obj) {
                if (obj.hasOwnProperty(key)) {
                    list.push({
                        name: key,
                        enabled: obj[key].enabled !== undefined ? obj[key].enabled : null,
                        strategy: obj[key].strategy || null
                    });
                }
            }
            return list;
        } catch (e) {
            return [];
        }
    }

    /**
     * 将数组转回 JSON 字符串（用于编辑保存）。
     * 输入: [{name:'phone', enabled:false}]
     * 输出: '{"phone":{"enabled":false}}'
     */
    function buildFieldConfig(list) {
        if (!list || list.length === 0) return null;
        var obj = {};
        list.forEach(function(item) {
            var val = {};
            if (item.enabled !== null && item.enabled !== undefined) val.enabled = item.enabled;
            if (item.strategy) val.strategy = item.strategy;
            obj[item.name] = val;
        });
        return JSON.stringify(obj);
    }

    // 开关切换（实时生效）
    vm.toggle = function(config) {
        $http.put('/api/admin/masking-config/' + config.id + '/toggle').then(
            function() {
                AlertService.success('脱敏开关已切换');
                loadList();
            },
            function() {
                AlertService.error('操作失败');
                loadList();
            }
        );
    };

    vm.add = function() {
        // 弹出新增对话框
    };

    vm.edit = function(config) {
        // 弹出编辑对话框
    };

    vm.delete = function(id) {
        AlertService.confirm('确认删除？', function() {
            $http.delete('/api/admin/masking-config/' + id).then(function() {
                AlertService.success('已删除');
                loadList();
            });
        });
    };

    // 暴露工具函数给模板使用
    vm.parseFieldConfig = parseFieldConfig;
    vm.buildFieldConfig = buildFieldConfig;

    loadList();
}
```

### C. 设计约束总结

| 约束 | 选择 | 理由 |
|------|------|------|
| 脱敏层级 | Jackson HTTP 序列化层 | 无业务侵入，不影响 Core/Service 层逻辑 |
| 隔离 Redis | 双 ObjectMapper | HTTP: 含脱敏；Redis: 标准 Jackson，注解被忽略 |
| 控制粒度 | 接口级 + 字段级覆盖 | 注解定义默认行为，配置表 field_config 可覆盖任意字段 |
| 实时切换 | 更新 DB → 删除 Redis Key → 下次请求全量回源 | **所有实例实时生效，延迟 <10ms** |
| 请求级覆盖 | `X-Masking: true/false` 请求头 | 导出/打印场景需要原值 |
| 集群一致 | Redis 共享缓存（单 Key 存全量配置 JSON） | 任何实例改配置 → Redis Key 被删 → 其他实例下次请求 MISS 回源 DB |
| 容灾 | 无本地缓存，Redis 挂掉时直接回源 DB | Redis 不可用时：查询降级为查 DB，配置变更延迟到 Redis 恢复 |
