# 批处理异步导出脱敏方案

> **适用场景**: Spring Boot + JDBC Template + ExcelUtil 批处理导出  
> **驱动方式**: 纯配置表驱动，无需注解  
> **策略复用**: 与 HTTP 脱敏方案共用 `MaskingStrategy` 枚举

## 1. 与 HTTP 方案对比

| 对比项 | HTTP 脱敏（脱敏.md） | 批处理导出脱敏 |
|--------|---------------------|--------------|
| 驱动方式 | 注解 + 配置表覆盖 | 纯配置表驱动 |
| 配置表 | `sys_masking_config` | `ams_querycontrol_td` 加字段 |
| 控制粒度 | 请求头 + 接口级 + 字段级 | 任务级 + 类型级 + 字段级 |
| 策略 | `MaskingStrategy` 枚举 | 同一个枚举 |
| 执行时机 | Jackson 序列化时 | 业务层（ExcelUtil 之前） |
| 数据操作 | 不修改原对象 | 原地修改（分页处理） |
| 上下文 | `MaskingContext` ThreadLocal | 无（直接传参） |

## 2. 配置表设计

### 2.1 导出类型配置表 `ams_querycontrol_td` 加字段

```sql
ALTER TABLE ams_querycontrol_td 
  ADD masking_enabled VARCHAR2(1) DEFAULT '1' 
  COMMENT '该类型导出是否脱敏 1=开 0=关';

ALTER TABLE ams_querycontrol_td 
  ADD masking_config CLOB DEFAULT NULL 
  COMMENT '字段脱敏规则 JSON，格式: {"字段名":{"strategy":"策略名"}}';
```

### 2.2 masking_config JSON 结构

```json
{
  "字段名": {
    "strategy": "策略名"
  }
}
```

**规则说明**:
- `strategy`: 对应 `MaskingStrategy` 枚举值
- 字段不在 JSON 中 → 该字段不脱敏
- JSON 为 null 或空 → 该类型所有字段都不脱敏
- 字段名使用驼峰命名（如 `realName`、`bankCard`）

### 2.3 数据示例

| query_id | query_name | masking_enabled | masking_config |
|----------|-----------|-----------------|----------------|
| 1001 | 用户信息导出 | 1 | `{"phone":{"strategy":"PHONE"},"realName":{"strategy":"CHINESE_NAME"}}` |
| 1002 | 订单导出 | 1 | `{"receiverPhone":{"strategy":"PHONE"},"receiverName":{"strategy":"CHINESE_NAME"}}` |
| 1003 | 统计报表导出 | 0 | NULL |
| 1004 | 管理员调试导出 | 1 | `{"phone":{"strategy":"PHONE"},"idCard":{"strategy":"ID_CARD"},"bankCard":{"strategy":"BANK_CARD"}}` |

### 2.4 任务表加字段

```sql
ALTER TABLE sys_export_task
  ADD masking_enabled VARCHAR2(1) DEFAULT NULL 
  COMMENT '单次任务脱敏覆盖 NULL=用类型配置 0=关 1=开';
```

**控制优先级**:

```
任务级 masking_enabled（NULL=跳过，非NULL=以此为准）
  ↓ 如果为 NULL
类型级 masking_enabled
  ↓ 如果为 1
按 masking_config 执行脱敏
```

## 3. VO 类设计

### 3.1 脱敏规则配置 VO `FieldMaskingRule`

```java
package com.yourcompany.batch.vo;

import com.yourcompany.common.enums.MaskingStrategy;

/**
 * 单个字段的脱敏规则。
 * 从 masking_config JSON 解析而来。
 *
 * JSON 示例: {"phone": {"strategy": "PHONE"}}
 * 解析后:    FieldMaskingRule(name="phone", strategy=PHONE, enabled=null)
 */
public class FieldMaskingRule {

    /** 字段名（对应 Map 的 key 或 VO 的字段名） */
    private String name;

    /** 脱敏策略 */
    private MaskingStrategy strategy;

    /** 是否启用，null=启用，false=关闭 */
    private Boolean enabled;

    public FieldMaskingRule() {}

    public FieldMaskingRule(String name, MaskingStrategy strategy, Boolean enabled) {
        this.name = name;
        this.strategy = strategy;
        this.enabled = enabled;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public MaskingStrategy getStrategy() { return strategy; }
    public void setStrategy(MaskingStrategy strategy) { this.strategy = strategy; }

    public Boolean getEnabled() { return enabled; }
    public void setEnabled(Boolean enabled) { this.enabled = enabled; }
}
```

### 3.2 解析工具 `MaskingConfigParser`

```java
package com.yourcompany.batch.util;

import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.yourcompany.batch.vo.FieldMaskingRule;
import com.yourcompany.common.enums.MaskingStrategy;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;

/**
 * 解析 masking_config JSON 为脱敏规则列表。
 *
 * 输入:  {"phone":{"strategy":"PHONE"},"realName":{"strategy":"CHINESE_NAME"}}
 * 输出:  [FieldMaskingRule(name=phone, strategy=PHONE),
 *         FieldMaskingRule(name=realName, strategy=CHINESE_NAME)]
 */
public class MaskingConfigParser {

    private static final ObjectMapper MAPPER = new ObjectMapper();

    /**
     * 解析 JSON 字符串为脱敏规则列表。
     *
     * @param json masking_config JSON（可为 null 或空）
     * @return 脱敏规则列表（空列表=不脱敏）
     */
    public static List<FieldMaskingRule> parse(String json) {
        if (json == null || json.trim().isEmpty()) {
            return Collections.emptyList();
        }
        try {
            Map<String, FieldConfig> map = MAPPER.readValue(
                    json, new TypeReference<Map<String, FieldConfig>>() {});

            List<FieldMaskingRule> rules = new ArrayList<>();
            for (Map.Entry<String, FieldConfig> entry : map.entrySet()) {
                FieldMaskingRule rule = new FieldMaskingRule();
                rule.setName(entry.getKey());
                if (entry.getValue() != null) {
                    rule.setStrategy(entry.getValue().getStrategy());
                    rule.setEnabled(entry.getValue().getEnabled());
                }
                rules.add(rule);
            }
            return rules;
        } catch (Exception e) {
            // JSON 解析失败，返回空列表
            return Collections.emptyList();
        }
    }

    /** JSON 中单个字段的配置结构 */
    private static class FieldConfig {
        private MaskingStrategy strategy;
        private Boolean enabled;

        public MaskingStrategy getStrategy() { return strategy; }
        public void setStrategy(MaskingStrategy strategy) { this.strategy = strategy; }
        public Boolean getEnabled() { return enabled; }
        public void setEnabled(Boolean enabled) { this.enabled = enabled; }
    }
}
```

## 4. 脱敏服务

### 4.1 `ExportMaskingService`

```java
package com.yourcompany.batch.service;

import com.yourcompany.batch.util.MaskingConfigParser;
import com.yourcompany.batch.vo.FieldMaskingRule;
import com.yourcompany.common.enums.MaskingStrategy;
import org.springframework.stereotype.Service;

import java.lang.reflect.Field;
import java.util.List;
import java.util.Map;

/**
 * 批处理导出脱敏服务。
 *
 * 在 ExcelUtil 写文件之前调用，对导出数据执行脱敏。
 * 支持 Map 类型（JdbcTemplate queryForList）和 VO 类型（反射）。
 *
 * 无状态，无 ThreadLocal，线程安全。
 */
@Service
public class ExportMaskingService {

    /**
     * 判断某次导出是否应该脱敏。
     * 优先级: 任务级 > 类型级
     *
     * @param taskEnabled  任务表的 masking_enabled（NULL=跳过）
     * @param typeEnabled  类型表的 masking_enabled
     * @return 是否脱敏
     */
    public boolean shouldMask(Boolean taskEnabled, Boolean typeEnabled) {
        if (taskEnabled != null) return taskEnabled;
        return Boolean.TRUE.equals(typeEnabled);
    }

    /**
     * 对导出数据执行脱敏。
     * 原地修改每行数据，返回同一引用。
     *
     * @param data         原始数据列表（每页 4000~6000 条）
     * @param maskingConfig masking_config JSON（null=不脱敏）
     * @return 脱敏后的数据（同一引用）
     */
    public List<Object> mask(List<Object> data, String maskingConfig) {
        if (data == null || data.isEmpty() || maskingConfig == null) {
            return data;
        }

        List<FieldMaskingRule> rules = MaskingConfigParser.parse(maskingConfig);
        if (rules.isEmpty()) {
            return data;
        }

        for (Object row : data) {
            maskRow(row, rules);
        }
        return data;
    }

    /** 对单行数据执行脱敏 */
    private void maskRow(Object row, List<FieldMaskingRule> rules) {
        if (row instanceof Map) {
            maskMapRow((Map<String, Object>) row, rules);
        } else {
            maskVoRow(row, rules);
        }
    }

    /**
     * Map 类型脱敏：直接按 key 取值，替换为脱敏后的值。
     * 适用于 jdbcTemplate.queryForList() 返回的结果。
     */
    @SuppressWarnings("unchecked")
    private void maskMapRow(Map<String, Object> map, List<FieldMaskingRule> rules) {
        for (FieldMaskingRule rule : rules) {
            if (rule.getEnabled() != null && !rule.getEnabled()) continue;
            if (rule.getStrategy() == null) continue;

            Object val = map.get(rule.getName());
            if (val instanceof String) {
                map.put(rule.getName(), rule.getStrategy().mask((String) val));
            }
        }
    }

    /**
     * VO 类型脱敏：通过反射按字段名取值，替换为脱敏后的值。
     * 支持父类字段查找。
     */
    private void maskVoRow(Object row, List<FieldMaskingRule> rules) {
        for (FieldMaskingRule rule : rules) {
            if (rule.getEnabled() != null && !rule.getEnabled()) continue;
            if (rule.getStrategy() == null) continue;

            try {
                Field field = findField(row.getClass(), rule.getName());
                if (field != null) {
                    field.setAccessible(true);
                    Object val = field.get(row);
                    if (val instanceof String) {
                        field.set(row, rule.getStrategy().mask((String) val));
                    }
                }
            } catch (Exception e) {
                // 字段不存在或不可访问，跳过
            }
        }
    }

    /** 递归查找字段（包括父类，直到 Object） */
    private Field findField(Class<?> clazz, String fieldName) {
        while (clazz != null && clazz != Object.class) {
            try {
                return clazz.getDeclaredField(fieldName);
            } catch (NoSuchFieldException e) {
                clazz = clazz.getSuperclass();
            }
        }
        return null;
    }
}
```

## 5. 导出流程集成

### 5.1 调用示例

```java
package com.yourcompany.batch.export;

import com.yourcompany.batch.service.ExportMaskingService;
import com.yourcompany.batch.util.MaskingConfigParser;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.core.RowMapper;
import org.springframework.stereotype.Service;

@Service
public class ExportService {

    @Autowired
    private JdbcTemplate jdbcTemplate;

    @Autowired
    private ExportMaskingService maskingService;

    @Autowired
    private ConfigRepository configRepository;

    @Autowired
    private ExcelUtil excelUtil;

    /**
     * 执行导出。
     * 在分页查询后、ExcelUtil 写文件前调用脱敏。
     */
    public void doExport(ExportTask task) {
        // 1. 查导出类型配置
        AmsQuerycontrolTd typeConfig = configRepository
                .findByQueryId(task.getQueryId());

        // 2. 判断是否脱敏
        boolean enabled = maskingService.shouldMask(
                task.getMaskingEnabled(),     // 任务级（NULL=跳过）
                typeConfig.getMaskingEnabled() // 类型级
        );

        // 3. 获取脱敏配置
        String maskingConfig = enabled
                ? typeConfig.getMaskingConfig() : null;

        // 4. 分页查询（每页 5000 条）
        int page = 0;
        int pageSize = 5000;
        String sql = typeConfig.getSqlContent();

        while (true) {
            List<Object> pageData = jdbcTemplate.query(
                    sql + " LIMIT " + pageSize + " OFFSET " + (page * pageSize),
                    rowMapper
            );
            if (pageData.isEmpty()) break;

            // 5. 脱敏（在传入 ExcelUtil 之前）
            if (enabled) {
                maskingService.mask(pageData, maskingConfig);
            }

            // 6. 写入 Excel
            excelUtil.writeRows(pageData, ...);

            page++;
        }
    }
}
```

### 5.2 数据流

```
导出任务创建
  ↓
读取任务类型 → 查 ams_querycontrol_td
  ↓
判断脱敏: 任务级 masking_enabled → 类型级 masking_enabled
  ↓ (如果开启)
分页执行 SQL（4000~6000条/页）
  ↓
List<Object>（Map 或 VO 类型）
  ↓
ExportMaskingService.mask(pageData, maskingConfig)
  ↓ 遍历每行:
  ├── Map 类型 → 按 key 取值 → 脱敏 → 写回 Map
  └── VO 类型 → 反射取字段值 → 脱敏 → 写回字段
  ↓
脱敏后的 List<Object>
  ↓
ExcelUtil 写文件 → 输出 Excel
```

### 6.2 对话框设计

```
┌─────────────────────────────────────────────┐
│  配置脱敏规则 - 用户信息导出                   │
├─────────────────────────────────────────────┤
│  字段名        策略           操作           │
│  ─────────────────────────────────────────  │
│  phone         [PHONE    ▼]  [删除]        │
│  realName      [CHINESE_NAME▼] [删除]       │
│  idCard        [ID_CARD   ▼]  [删除]        │
│  ─────────────────────────────────────────  │
│  [+ 添加字段]                                │
├─────────────────────────────────────────────┤
│           [取消]  [保存]                      │
└─────────────────────────────────────────────┘
```

### 6.3 前端控制器

```javascript
angular.module('app').controller('ExportMaskingConfigController',
    ['$scope', '$http', 'AlertService', ExportMaskingConfigController]);

function ExportMaskingConfigController($scope, $http, AlertService) {
    var vm = this;
    vm.types = [];
    vm.currentConfig = null;
    vm.fields = [];

    // 加载导出类型列表
    function loadTypes() {
        $http.get('/api/admin/export-type/list').then(function(resp) {
            vm.types = resp.data.data || [];
        });
    }

    // 打开配置对话框
    vm.openConfig = function(type) {
        vm.currentConfig = type;
        vm.fields = parseFields(type.maskingConfig);
        // 弹出对话框
    };

    // 解析 masking_config JSON 为数组
    function parseFields(json) {
        if (!json) return [];
        try {
            var obj = JSON.parse(json);
            var list = [];
            for (var key in obj) {
                if (obj.hasOwnProperty(key)) {
                    list.push({
                        fieldName: key,
                        strategy: obj[key].strategy || 'PHONE'
                    });
                }
            }
            return list;
        } catch (e) {
            return [];
        }
    }

    // 数组转回 JSON
    function buildConfig(fields) {
        if (!fields || fields.length === 0) return null;
        var obj = {};
        fields.forEach(function(f) {
            obj[f.fieldName] = { strategy: f.strategy };
        });
        return JSON.stringify(obj);
    }

    // 添加字段
    vm.addField = function() {
        vm.fields.push({ fieldName: '', strategy: 'PHONE' });
    };

    // 删除字段
    vm.removeField = function(index) {
        vm.fields.splice(index, 1);
    };

    // 保存
    vm.save = function() {
        var config = buildConfig(vm.fields);
        $http.put('/api/admin/export-type/' + vm.currentConfig.id + '/masking', {
            maskingEnabled: vm.currentConfig.maskingEnabled,
            maskingConfig: config
        }).then(function() {
            AlertService.success('保存成功');
            loadTypes();
        });
    };

    loadTypes();
}
```

### A. MaskingStrategy 枚举（复用 HTTP 方案）

```java
public enum MaskingStrategy {
    PHONE(v -> { ... }),           // 手机号: 138****1234
    PHONE_LAST4(v -> { ... }),     // 手机号: *******1234
    ID_CARD(v -> { ... }),         // 身份证: 110101********1234
    EMAIL(v -> { ... }),           // 邮箱: a***@domain
    CHINESE_NAME(v -> { ... }),    // 中文姓名: 张**
    FIXED_PHONE(v -> { ... }),     // 固定电话: 010****1234
    BANK_CARD(v -> { ... }),       // 银行卡: 6222********1234
    LICENSE_PLATE(v -> { ... }),   // 车牌号: 京A****56
    ADDRESS(v -> { ... }),         // 地址: 北京市***
    PASSWORD(v -> "******"),       // 密码: 全掩
    NONE(UnaryOperator.identity()),// 不脱敏
    CUSTOM(UnaryOperator.identity());
    // ... 完整实现见脱敏.md
}
```

### C. 设计约束总结

| 约束 | 选择 | 理由 |
|------|------|------|
| 驱动方式 | 纯配置表 | SQL 动态、VO 类型混杂，注解覆盖不了 |
| 配置表 | ams_querycontrol_td 加字段 | 复用现有导出类型管理，不新增表 |
| 控制粒度 | 任务级 + 类型级 + 字段级 | 三层控制，灵活够用 |
| 策略复用 | MaskingStrategy 枚举 | 与 HTTP 方案共用，不重复定义 |
| 执行时机 | ExcelUtil 之前 | 原地修改数据，不影响 SQL 执行层 |
| 数据操作 | 原地修改 List | 分页处理，内存友好 |
| 线程安全 | 无状态 Service | 纯方法调用，无 ThreadLocal |
